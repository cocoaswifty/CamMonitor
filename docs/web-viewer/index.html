不同 Wi-Fi 遠端觀看

連線使用 WSS MQTT 訊令及加密 WebRTC 媒體。遇到對稱型 NAT 或嚴格的行動網路時，請在 Android 配對畫面填入 TURN 伺服器連線資訊；沒有 TURN 無法保證每種網路都能成功。

本網頁不儲存影片；配對的私鑰保存在目前瀏覽器的 IndexedDB。使用無痕模式、清除網站資料或 Safari 自動清理資料後，可能需要重新配對。

公開 MQTT Broker 僅供原型測試；正式遠端監控建議改用專屬 TLS MQTT Broker，並使用短效 TURN 憑證。
